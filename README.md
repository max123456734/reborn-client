# Reborn Client

An independent Fabric client mod for Minecraft **1.21.11**, with a dark custom click GUI and modular client-side utilities.

## Build

Requires Java 21 and Gradle.

```bash
gradle build
```

The remapped Fabric JAR is produced in `build/libs/`.

## Controls

- **Right Shift** — open/close the Reborn click GUI.
- Click a supported module row to toggle it.

## Implemented features

- Dark custom ClickGUI
- Fullbright
- Auto Sprint
- Module registry and tick lifecycle

Only implemented features are registered in the GUI. Features that are not implemented are not presented as working.
